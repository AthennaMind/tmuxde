Sessions live on the host and persist across disconnects. Close the tab, come
back tomorrow, and everything is where you left it.

## Sessions

| Action | How                                             |
| ------ | ----------------------------------------------- |
| List   | Automatic on connect; pull to refresh on mobile |
| Create | The **+** button, or the empty-state button     |
| Attach | Click a session card or a desktop tab           |
| Rename | Inline on the session card                      |
| Kill   | The kill button, behind a confirmation dialog   |
| Detach | The toolbar, or the tmux sheet on mobile        |

Creating takes an optional **name**, **working directory** and **command** to
run instead of the default shell. The client attaches to the new session
automatically.

Attaching clears the terminal and connects to that session's PTY. The previously
attached session is detached but keeps running.

The last active session is remembered and restored on the next page load.

### Session cards

Each card shows a status dot — attached, recently active, or detached — the
window count, and the creation and activity timestamps. Expanding a card lists
its windows and panes.

### Desktop tabs

Sessions you have opened appear as tabs in the header for quick switching, each
with a close button. On mobile, swiping left and right switches session instead
(or pane, when the window has more than one).

### Exits

When a session's process exits, the client shows an alert and removes it from
the list.

## Panes

| Action                          | Where                                                       |
| ------------------------------- | ----------------------------------------------------------- |
| List                            | The pane-count button, or the pane sheet                    |
| Split horizontally / vertically | Toolbar buttons, tmux sheet, long-press the FAB             |
| Select                          | Pane sheet, or swipe on mobile                              |
| Zoom                            | Pane sheet, tmux sheet                                      |
| Resize                          | Resize mode — a D-pad overlay, 5 cells per press, repeating |
| Swap                            | tmux sheet                                                  |
| Kill                            | tmux sheet, with confirmation                               |
| Capture contents                | Copy mode overlay                                           |

### Auto-zoom

On mobile, an optional setting zooms the active pane automatically on attach and
after a split. A split pane on a phone screen is usually unreadable, so this is
on by preference rather than by default behaviour of tmux.

### Copy mode

The copy-mode overlay captures a pane's contents and renders them read-only in
Monaco, with a pane switcher, a recapture button and Copy All. It is a practical
substitute for `tmux copy-mode` key sequences on a touch screen. `tmux:copy-mode`
and `tmux:prefix` are also available directly from the tmux sheet.
